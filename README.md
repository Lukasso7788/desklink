# DeskLink 0.3.0 для Windows

Готовая программа: `DeskLink.exe` (скачать из [GitHub Releases](https://github.com/lukasso7788/desklink/releases/latest)). Python устанавливать на целевом компьютере не нужно. На ноутбуке нужен браузер. Собственный сервер в облаке не используется.

## Подключение дома

1. На управляемом компьютере запустите `DeskLink.exe` и нажмите **Включить доступ**. До нажатия программа не слушает сеть.
2. Оба устройства подключите к одной домашней сети. В окне появятся адреса. `127.0.0.1` подходит только для проверки на самом компьютере; с ноутбука используйте адрес вида `https://192.168.…:47831`.
3. Для входящего подключения требуется разрешение брандмауэра. В комплекте есть `Enable-Network.ps1`: положите его рядом с EXE, откройте PowerShell от администратора в этой папке и выполните `powershell -ExecutionPolicy Bypass -File .\Enable-Network.ps1`. Правило ограничено этой программой, TCP-портом 47831, локальной подсетью и диапазоном VPN Tailscale. Скрипт не запускается автоматически. Если Windows уже показала сетевой запрос, его решение принимает владелец устройства.
4. Откройте адрес в браузере ноутбука. Приложение использует собственный HTTPS-сертификат: при первом входе браузер покажет предупреждение. До продолжения самостоятельно откройте сведения сертификата и сравните **полный отпечаток SHA-256** с окном DeskLink на компьютере. Если браузер/политика не позволяет проверить сертификат или продолжить, остановитесь; не отключайте общую проверку сертификатов. Не устанавливайте сертификат в корневое хранилище только ради этой программы.
5. Введите пароль из окна DeskLink. Он меняется при каждом запуске и после остановки доступа.
6. По умолчанию работает просмотр. Для управления отметьте **Мышь и клавиатура**, затем щёлкните по изображению экрана. Для русского текста и других алфавитов используйте отдельное поле **Ввести текст**; ввод попадёт в ранее выбранное окно на компьютере.
7. Нажмите **Отключиться** в браузере или **Остановить доступ** на компьютере. Закрытие окна DeskLink также останавливает сервер.

## Подключение через интернет

Транспорт первой версии — личная VPN-сеть. DeskLink передаёт экран и ввод самостоятельно; VPN соединяет устройства за разными роутерами. Облачный relay DeskLink и подключение по ID пока не реализованы.

1. Установите [Tailscale для Windows](https://tailscale.com/download/windows) на обоих устройствах и подключите их к одной своей сети Tailscale. Вход в аккаунт выполняете самостоятельно.
2. Узнайте Tailscale IPv4 управляемого компьютера в приложении Tailscale: обычно это адрес `100.x.y.z`.
3. Включите DeskLink и разрешите сетевой доступ описанным выше скриптом.
4. На ноутбуке откройте `https://100.x.y.z:47831`, проверьте полный отпечаток сертификата и введите пароль DeskLink.

Не нужно включать RDP или открывать порт роутера. VPN должна разрешать соединение между этими двумя устройствами. Это использование IP-сети Tailscale, а не протокола Windows RDP. Принцип сети описан в [официальной документации Tailscale](https://tailscale.com/docs/solutions/access-remote-desktops-using-windows-rdp).

## Что умеет эта версия

- Основной монитор, JPEG до 2560×1600 по умолчанию или оригинальное разрешение, примерно 5–6 кадров/с в зависимости от захвата и сети.
- Перемещение, клики, перетаскивание, колесо мыши, обычные клавиши, сочетания и ввод Unicode-текста.
- Один управляющий сеанс одновременно; пароль, защищённая cookie сроком на час, защита от перебора и посторонних сайтов.
- Видимый статус на компьютере, остановка доступа и освобождение удалённо зажатых клавиш при завершении сеанса.
- HTTPS; закрытый ключ сертификата хранится с защитой Windows DPAPI в `%LOCALAPPDATA%\DeskLink`.

Пока нет звука, передачи файлов, второго монитора, автозапуска, учётных записей DeskLink, управления до входа в Windows, пробуждения компьютера и автоматического восстановления соединения. Это интерактивная программа, не Windows-служба. UAC, экран блокировки и Ctrl+Alt+Del не обслуживаются. Ввод в приложения администратора может блокировать Windows; это [ограничение SendInput](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-sendinput). Сочетания вроде Alt+Tab или Ctrl+W может перехватывать браузер ноутбука.

Сертификат действует год; при смене IP возможна дополнительная ошибка имени. Всегда сравнивайте отпечаток, не полагайтесь только на имя DeskLink. После удаления файлов identity будет создан новый сертификат с новым отпечатком. Не передавайте папку `%LOCALAPPDATA%\DeskLink` другим людям. EXE пока не подписан сертификатом издателя.

## Сборка и проверки

```powershell
cd desklink
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m unittest -v test_host
.\build.ps1
```

Файлы архитектуры, текущее состояние и продолжение разработки: `PROJECT_CONTEXT.md`. Фактические результаты проверок: `VERIFICATION.md`.

Дополнительный браузерный тест: `.\.venv\Scripts\python.exe test_browser.py`. В тесте указан путь к имеющемуся Chromium; при переносе окружения его нужно скорректировать. Для обычного запуска DeskLink эти инструменты не нужны.


## Качество и курсор в 0.2.0

В браузере выберите «Баланс» для более слабого соединения, «Чётко» (по умолчанию) для текста или «Оригинал» для полного разрешения монитора. У «Оригинала» выше нагрузка на сеть и возможна большая задержка. «Масштаб 100%» показывает пиксели без уменьшения, с прокруткой; «Вписать в окно» возвращает общий вид. Бирюзовый маркер показывает фактический удалённый курсор. При включённом управлении форма курсора меняется для текста, ссылок, изменения размера и ожидания. Нестандартные курсоры приложений могут отображаться обычной стрелкой.

## Обновления через интернет

Официальные релизы: https://github.com/lukasso7788/desklink/releases/latest . В окне программы нажмите «Проверить и скачать обновление»; адрес уже заполнен. Если появилась более новая версия, EXE скачивается в папку Downloads после проверки SHA-256. Текущее соединение продолжает работать. Для установки завершите текущий сеанс, закройте старую программу и запустите скачанный EXE. Автоматической замены запущенной программы нет. В самой первой версии кнопки обновления не было: 0.2.0 нужно скачать и запустить вручную один раз. Не меняйте адрес обновлений на неизвестный источник.

Репозиторий и релизы публичные; для скачивания EXE не нужен вход в GitHub. Настройки доступа и TLS-сертификат сохраняются на управляемом компьютере в профиле Windows и не включаются в релизы.


## Быстрое подключение и клиент для ноутбука (0.3.0)

На управляемом компьютере используйте **DeskLink.exe**, на ноутбуке — **DeskLinkClient.exe** из того же релиза. Основной экран и управление остаются в обычном браузере. Обновите Host до 0.3.0: старый Host не поддерживает привязки.

**Один раз:** включите доступ в Host; запустите Client на ноутбуке; введите адрес и текущий пароль из окна Host; нажмите «Привязать компьютер». Сравните полный SHA-256 в диалоге клиента с отпечатком в окне Host. Подтверждайте только при полном совпадении.

**В дальнейшем:** запустите Client, выберите сохранённый компьютер и нажмите «Открыть экран в браузере». Client сам получает одноразовую ссылку и открывает браузер без повторного ввода пароля. При первом посещении браузер отдельно проверяет сертификат; настройка клиента не отменяет проверку сертификата в браузере. «Скопировать ссылку» получает такую же ссылку без запуска браузера. Не пересылайте её посторонним: она даёт доступ к экрану.

На ноутбуке есть кнопка «Установить клиент на этот ноутбук»: она копирует EXE в `%LOCALAPPDATA%/Programs/DeskLink` и добавляет **DeskLink Client** в меню Пуск. Права администратора и автозапуск не требуются. Если достаточно portable-версии, просто сохраните EXE в удобной папке. Сам Host этой кнопкой не устанавливается.

Client сохраняет привязку на 90 дней с защитой DPAPI текущего профиля Windows; пароль Host не сохраняется. На компьютере хранятся только хеши ключей устройств. Привязка переживает перезапуск Host и смену его временного пароля, но Host должен быть открыт и доступ вручную включён. Чтобы немедленно отозвать все привязки и закрыть сеансы, нажмите **«Сбросить привязки»** в Host и подтвердите. Срок привязки не продлевается автоматически. При изменении IP-адреса добавьте компьютер по новому адресу; для устойчивого адреса можно использовать постоянный IP VPN.

Без Client тоже стало быстрее: в Host добавлены «Скопировать адрес», «Скопировать пароль» и **«Скопировать ссылку для входа»**. Быстрая ссылка одноразовая, действует 5 минут; создание новой отменяет предыдущую. Секрет находится во фрагменте URL, не отправляется при GET, и удаляется из адресной строки перед обменом на обычную защищённую cookie. После входа доступен просмотр; мышь и клавиатуру по-прежнему включают отдельно.

LAN/VPN всё ещё требуются. Client не создаёт публичный туннель и не включает выключенный компьютер. При открытии новой версии сначала закройте старую: одновременно порт 47831 может занимать только одна копия Host.
